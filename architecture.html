Layer 4 · Detection Algorithms — run on every bar update
⚡ Vol Spike
1Split window — 1-min vs 4-min baseline
2vol_1m = Σ(price×size) last 60s
3basePerMin = vol_4m / 4
4If basePerMin > 0:
ratio = vol_1m / basePerMin
≥ tier.spike → SPIKE
5If basePerMin = 0: NEW ACTIVITY (∞)
6volSpikeCache → 5-min TTL
Input: symbolData
Output: volAlerts[]
Tier thresholds:
nano 10× $10K 8%
small 8× $40K 5%
mid 5× $100K 3%
🎯 Sweep + Confidence
1sweepAcc flushed end-of-batch
2Signal 1 (45%): intra-sweep price trend
lastPrice vs firstPrice
3Signal 2 (35%): VWAP vs prePrice
(clean ref before sweep)
4Signal 3 (20%): upTicks vs downTicks
5Weighted vote → bull/bear/neutral
6Confidence 0-99: A(move 35) + B(agree 30) + C(ticks 20) + D(consistency 14)
Input: sweepAcc{}
Output: sweepAlerts[]
$ thresholds:
nano $10K direct / $50K voice
small $25K / $100K
mid $75K / $250K
🔥 Move % Bull / Bear
1rows[] from server aggregates
2Qualify: |Δ%| ≥ tier.delta
&& val ≥ tier.valK
&& trades ≥ tier.trades
3Skip suppressedSyms
4New entry → auto-select chart + log 'new'
5Escalation: Δ ≥ 1.5× prev && ≥ 2× threshold → log 'escalation'
65-min TTL from firstTs (hard)
Input: symbolData aggregates
Output: alertHistory Map
Qual thresholds:
nano bull 4% $20K 1tr
nano bear 6% $20K 2tr
mid bull 2% $1M 1tr
⚙ Control Panel (localStorage: tierConfig + sweepConfig) feeds threshold values into all three detectors at runtime. Changes take effect on next detection cycle without page reload. Tier boundaries (maxCapM), spike multipliers, delta %, valK, trades, flashM, sweep $K thresholds — all user-tunable.
